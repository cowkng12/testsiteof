# Zire - Кофейня

Сайт кофейни Zire с меню, категориями блюд, избранным и корзиной.

## Возможности

- 📱 Адаптивный дизайн
- 🌓 Темная и светлая темы
- ❤️ Избранные блюда
- 🛒 Корзина с контролами количества
- 🔍 Поиск по меню
- 📂 Категории блюд

## Технологии

- HTML5
- CSS3 (CSS Variables для тем)
- Vanilla JavaScript
- LocalStorage для сохранения данных

## Запуск локально

Просто откройте `index.html` в браузере.

## Деплой на Render

1. Загрузите проект на GitHub
2. Подключите репозиторий к Render
3. Render автоматически обнаружит конфигурацию из `render-config.yaml`
4. Сайт будет доступен по адресу `https://ваш-сайт.onrender.com`

## Структура проекта

```
.
├── index.html          # Главная страница
├── style.css           # Стили
├── script.js           # JavaScript логика
├── images/             # Изображения блюд
├── render-config.yaml  # Конфигурация для Render
└── README.md           # Этот файл
```
